# Web_Development_Lab_Exercise

## About This Project
This repository contains my Web Development Lab assignments completed as part of my programming course at BossCoder School of Technology.

The purpose of this project is to learn and practice web development concepts, Git, and GitHub.

## Modules Covered

### Module 1: Terminal, Git & GitHub
- P1: Project folder and terminal navigation
- P2: Portfolio repository with an initial commit
- P3: Feature-branch Git workflow
- P4: GitHub README and version tags

### Module 2: HTML and CSS Foundations
- P5: HTML and CSS basics
- P6: HTML practice
- P7: CSS styling
- P8: HTML and CSS practice
- P9: HTML and CSS project

### Module 3: CSS Layout Systems

- P11: CSS layout practice

## Technologies Used

## How to Run the Projects
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required module and assignment folder.
4. Open the "index.html" file in a web browser.
